Servidor fora do ar

Este exemplo carrega https://localhost:5000, servido pelo servidor.mts que acompanha a pasta. A conexão falhou, então provavelmente o servidor não está rodando.

  1. Gere os certificados: ./ssl/setup.sh
  2. Importe rootCA.crt e client.p12 no sistema
  3. Em outro terminal, suba o servidor: npm run servidor
  4. Reinicie este aplicativo

Com tudo no lugar, esta janela mostra approved no lugar desta página.
